При поступлении N-го числа, нужно распределить числа таким образом
дабы получилось по итогу максимальныя сумма, при перемножении

Оптимально, когда происходит деление на 3 без остатка, для расчёта 
использовать максимальное колличество множителей, с минимальным числом

Если число не делиться на 3 без остатка, то нужно проверить, не будет ли лучше 
распределение из разрядя 2*2*3
